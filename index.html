วิธีใช้งาน Teacher Prompt Studio

4 ขั้นตอนง่าย ๆ สำหรับครู ไม่ต้องเขียนโค้ดเป็น

  1. 1. กรอกเนื้อหาที่สอน

    เลือกวิชา ระดับชั้น พิมพ์หัวข้อและจุดประสงค์ หรือกดเลือกจากตัวอย่างวิชาด้านบน

  2. 2. ตั้งค่าโจทย์เฉพาะบุคคล

    เปิดใช้การสุ่มตามเลขที่นักเรียน เพื่อลดการลอกกัน และเลือกว่าจะแสดงเฉลยหรือคำแนะนำอย่างไร

  3. 3. คัดลอก Prompt ไปวางใน AI

    กด "คัดลอก Prompt" แล้ววางใน ChatGPT, Gemini (แนะนำเปิดปุ่ม Canvas), Claude หรือ AI อื่น ๆ เพื่อแสดงหน้าเว็บให้ครูกดเล่นในแชทได้ทันที

  4. 4. ตรวจทานในโหมดครูและใช้งานจริง

    ลองกดปุ่ม "โหมดครู" ในเว็บที่ได้เพื่อเช็กโจทย์เลขที่ 1, 2 ก่อนสอนจริง หรือโหลดไฟล์ index.html ไปเปิดบนเครื่อง/ลง GitHub Pages

ใช้เลขที่นักเรียนกำหนดโจทย์ให้ต่างกันอย่างเป็นธรรม แต่ยังคงวัดจุดประสงค์เดียวกัน

Strategy A

เปลี่ยนตัวเลข (Numerical)

เหมาะกับคณิตฯ ฟิสิกส์ เคมี — สุ่มตัวเลขใหม่ตามเลขที่ พร้อมคำนวณเฉลยตรงตามโจทย์จริง

Strategy B

เปลี่ยนบริบท (Contextual)

เหมาะกับภาษา ศิลปะ การงาน — สลับบทอ่านหรือสถานการณ์ตามเลขที่ โดยใช้ Rubric ร่วมกัน

Strategy C

เปลี่ยนกรณีศึกษา (Case-Based)

เหมาะกับสังคมฯ สุขศึกษา — เปลี่ยนกรณีศึกษาโดยไม่บิดเบือนข้อเท็จจริง พร้อม Rubric เหตุผล

Strategy D

ผสมผสาน (Hybrid)

เหมาะกับวิชาบูรณาการหรือกำหนดเอง — เปลี่ยนทั้งบริบท ข้อมูล และตัวเลขร่วมกัน

การใช้เลขที่เป็น Seed ช่วยให้เปิดซ้ำได้ชุดเดิม แต่ไม่การันตีว่าไม่ซ้ำ 100% ครูควรตรวจเลขที่ตัวอย่างและเฉลยในโหมดครูก่อนใช้จริง
