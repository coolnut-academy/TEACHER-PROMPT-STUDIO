วิธีนำไปใช้กับ AI และข้อจำกัดเว็บ Static
  1. คัดลอก Prompt ด้านล่างแล้วนำไปวางใน ChatGPT, Gemini, Claude หรือ Coding Agent
  2. ตรวจทานก่อนสอนจริง: ลองกรอกเลขที่ 1, 2 และ 15 ในโหมดครู เพื่อตรวจความถูกต้องของโจทย์ เฉลย และ Rubric
  3. แชร์ผ่าน GitHub Pages: อัปโหลดไฟล์ที่ได้ขึ้น GitHub เพื่อแจกลิงก์ให้นักเรียนเปิดใช้งานได้ทันที

ใช้ เลขที่นักเรียน เป็นตัวกำหนดโจทย์ให้แตกต่างกันอย่างเป็นธรรม แต่ยังคงวัดจุดประสงค์การเรียนรู้เดียวกัน

Strategy A

Numerical Variation

เหมาะกับคณิตฯ ฟิสิกส์ เคมี — ใช้เลขที่สุ่มชุดตัวเลขที่คำนวณซ้ำได้เหมือนเดิม ตรวจช่วงค่าและคำนวณเฉลยสอดคล้องกัน

Strategy B

Contextual Variation

เหมาะกับภาษาไทย ภาษาต่างประเทศ ศิลปะ การงาน — หมุนเวียนคลังบทอ่านหรือสถานการณ์ โดยใช้ Rubric ร่วมกัน

Strategy C

Case-Based Variation

เหมาะกับสังคมฯ ประวัติศาสตร์ สุขศึกษา — เปลี่ยนกรณีศึกษาโดยไม่บิดเบือนข้อเท็จจริง พร้อม Rubric เหตุผล

Strategy D

Hybrid Variation

เหมาะกับวิชาบูรณาการหรือกำหนดเอง — ผสมผสานการเปลี่ยนตัวเลข ชุดข้อมูล บริบท และเงื่อนไขวิเคราะห์

การใช้เลขที่เป็น Seed ช่วยให้สร้างโจทย์ซ้ำได้แน่นอน แต่ไม่ได้รับประกันว่าไม่ซ้ำ 100% ครูควรตรวจเลขที่ตัวอย่างและเฉลยในโหมดครูก่อนนำไปใช้สอนจริง
